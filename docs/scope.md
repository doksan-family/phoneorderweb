# Phone Order Web Scope

## Included

이 앱은 휴대폰 판매 상품을 노출하고 결제 대신 상담 신청으로 전환하는 웹사이트다.

- 반응형 사용자 웹사이트
- 메인 페이지, 공통 상단 메뉴, 공통 푸터
- 메인 배너 또는 이벤트 배너 영역
- 카테고리별 상품 노출
- 상품 목록과 상품 상세
- 상품별 상담 신청
- 신청자 정보 기반 신청 내역 조회
- 구매후기, 공지사항, 고객센터, FAQ
- 이용약관, 개인정보처리방침, 마케팅 수신동의 안내
- 기본 SEO 메타 정보
- 관리자 로그인, 로그아웃, 대시보드
- 상담 신청 조회, 상세 확인, 상태 변경
- 상품, 카테고리, 배너, 구매후기, 공지사항, FAQ 기본 CMS
- 이미지 업로드 입력 UI
- 계약 범위 내 기능 오류 수정

## Excluded

아래 항목은 별도 견적 및 일정 협의 전까지 범위에서 제외한다.

- 일반 사용자 회원가입, 로그인, 소셜 로그인
- 온라인 결제, 장바구니, 주문 결제 시스템, PG사 연동
- 본인인증, 휴대폰 문자 인증
- SMS 알림, 카카오 알림톡, 카카오톡 상담 연결, 실시간 채팅
- 채팅 상담 관리자 시스템
- 통신사 정책 자동 크롤링
- 실시간 재고 연동, 실시간 가격 연동
- 통계 및 리포트 고도화
- 관리자 권한 등급 분리, 다중 관리자 계정 관리
- 고객 DB 마케팅 자동화
- 광고 추적 스크립트 고도화, 광고 운영
- 상품 대량 업로드, 상품 옵션 조합 관리
- ERP, CRM, 회계 프로그램 연동
- 유지보수 계약, 보안 관제, 서버 모니터링
- 원고 작성, 로고 제작, 브랜드 아이덴티티 디자인
- 상세페이지 전문 디자인 대행, 법률 검토
- 개인정보보호 관련 법률 자문
- 통신판매업 신고 또는 각종 인허가 대행
- 본 계약 범위를 초과하는 추가 페이지 또는 추가 기능

## Implementation Note

현재 구현은 화면과 로컬 동작을 검증하기 위한 Next.js 기반 MVP다. 실제 운영 전에는 데이터베이스, 관리자 인증, 이메일 발송, 이미지 저장소를 연결해야 한다.
